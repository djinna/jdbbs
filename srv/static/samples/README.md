# Typography sampler (generated)

`typography-sampler.pdf`, `chip-*.png` (2× thumbnails) and `page-*.png`
(lightbox views) are built by `typesetting/scripts/build-sampler.sh` and
shown on the transmittal's Typeface row. Do not edit by hand; rerun the
script when the fonts, the series template or the offered pairings change.
Fonts are subset-embedded in the PDF only — no font files live here.
